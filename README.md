# SWYNEX - Biological Dataset Selection

## 1. Introduction
Bioinformatics combines biology, computer science and statistical methods to analyse biological data.

This project focuses on selecting and describing a publicly available human gene expression dataset related to Type 2 Diabetes. The dataset is obtained from the National Center for Biotechnology Information (NCBI) Gene Expression Omnibus (GEO).

## 2. Dataset Information

- Dataset ID: GSE20966
- Repository: NCBI GEO
- Organism: Homo sapiens
- Study type: Gene expression profiling
- Technology: Affymetrix microarray
- Platform: GPL1352
- Total samples: 20
- Control samples: 10
- Type 2 Diabetes samples: 10
- Processed data size: Approximately 30 MB
- Raw supplementary data: Approximately 90.3 MB

## 3. Dataset Description
The dataset contains gene expression profiles of pancreatic beta-cell-enriched tissue obtained from human donors.

The study compares gene expression between non-diabetic control individuals and individuals with Type 2 Diabetes.

The samples were collected using laser capture microdissection, and gene expression was measured using the Affymetrix Human X3P microarray platform.

## 4. Research Question
Which genes show differences in expression between healthy individuals and individuals with Type 2 Diabetes, and how are these genes associated with pancreatic beta-cell function?

## 5. Objectives
1. Identify a publicly available biological dataset.
2. Understand the source and structure of gene expression data.
3. Compare the biological conditions represented in the dataset.
4. Explore the potential application of bioinformatics in diabetes research.
5. Identify opportunities for future computational gene expression analysis.
